# Changelog

## StickFlow 2.0.0 — 2026-11-24

Personal, self-contained edition.

- Rebranded the product and Skill as **StickFlow** (`stickflow`).
- Removed the upstream Git remote, GitHub metadata, sponsor blocks, community
  destinations and externally hosted media URLs. Documentation and samples now
  resolve inside this repository.
- Consolidated documentation to a single English README and local contributing
  guide.
- Added a local setup path: install the Node runtime, run the dependency doctor,
  and render the bundled B1 example end to end.
- Kept the complete A/B style system, the Code Engine runtime, the sound
  library, approved sample media and their license records.

## Earlier history

StickFlow derives from an MIT-licensed open-source stickman video project.
Functional history before this personal edition is preserved in the source
tree; see [LICENSE](LICENSE) for the original copyright notice.
